# Lever

The job boards of companies you choose that hire with Lever. Dossier reads each board's list of open jobs, with their whole text, and matches it to your search on your server: the search itself isn't sent anywhere.

- **Terms:** https://github.com/lever/postings-api (the Postings API is public and "designed to help you create a job site"; published postings "may be scraped by third parties")
- **Countries:** Every country
- **Kinds of work:** any
- **Access:** Official API
- **Key:** None. Add the companies' boards in Settings → Job search, one a line: a board's name, as in `jobs.lever.co/palantir`, or a link to it. Up to 25. Boards on Lever's EU host (`jobs.eu.lever.co`) aren't covered yet.
- **Credit:** None asked for. Each posting links to its page on the company's board.

Dossier asks up to four boards at a time and keeps each board's answer for half an hour. A board that can't be read is skipped and named.
