# Jobicy

Remote jobs from Jobicy's public API: the newest hundred, matched to your search on your server: every word in the title or company, Remote only, the country the job can be done from, and how recent.

- **Terms:** https://jobicy.com/jobs-rss-feed (credit Jobicy as the source with a link; apply links go to the job's page on Jobicy; don't present the listings as your own)
- **Countries:** Every country
- **Kinds of work:** any
- **Access:** Official API
- **Key:** None
- **Credit:** "Jobs from Jobicy", linked to jobicy.com. Each posting links to its page on Jobicy.

Dossier downloads the newest hundred at most once an hour, shared by every search.
