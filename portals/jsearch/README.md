# JSearch

Google for Jobs through OpenWeb Ninja's JSearch API: postings from LinkedIn, Indeed, Glassdoor, Stepstone and company sites, in most countries, with their whole text.

- **Terms:** https://www.openwebninja.com/terms
- **Countries:** Every country
- **Kinds of work:** any
- **Access:** Official API
- **Key:** A key from [OpenWeb Ninja](https://app.openwebninja.com) or RapidAPI. The free plan allows a small number of searches a month; each page of results is one.
- **Credit:** None asked for.

Built into Dossier: each release bundles this config, and newer versions reach installs through the catalog between releases.
