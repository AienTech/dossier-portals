# Bundesagentur für Arbeit

Germany's Federal Employment Agency's job board, through the access its own job search uses. It has no official API and its terms don't allow automated access, so it's listed only because Dossier comes with it: it's searched only after the user accepts its note, and never by the job agent.

- **Terms:** https://www.arbeitsagentur.de/datei/nutzungsbedingungen_ba036575.pdf
- **Countries:** DE
- **Kinds of work:** any
- **Access:** Unofficial
- **Key:** None.
- **Credit:** None asked for.

Built into Dossier: each release bundles this config, and newer versions reach installs through the catalog between releases.
