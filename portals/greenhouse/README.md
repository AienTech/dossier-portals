# Greenhouse

The job boards of companies you choose that hire with Greenhouse. Dossier reads each board's list of open jobs, with their whole text, and matches it to your search on your server: the search itself isn't sent anywhere.

- **Terms:** https://docs.greenhouse.io/job-board.html ("Job Board data is publicly available, so authentication is not required for any GET endpoints.")
- **Countries:** Every country
- **Kinds of work:** any
- **Access:** Official API
- **Key:** None. Add the companies' boards in Settings → Job search, one a line: a board's name, as in `boards.greenhouse.io/airbnb`, or a link to it. Up to 25.
- **Credit:** None asked for. Each posting links to its page on the company's board.

Dossier asks up to four boards at a time and keeps each board's answer for half an hour, so going back or Show more asks nothing again. A board that can't be read is skipped and named.
