# Himalayas

Remote jobs from Himalayas, searched by keyword and by the country each job can be done from, 20 to a page.

- **Terms:** https://himalayas.app/api and https://himalayas.app/terms (personal and commercial use without asking; a visible link to the job on Himalayas; Apply uses the job's `applicationLink` unchanged; the jobs aren't passed on to other job boards)
- **Countries:** Every country
- **Kinds of work:** any
- **Access:** Official API
- **Key:** None. Without a key, every caller shares one public allowance.
- **Credit:** "Jobs from Himalayas", linked to himalayas.app. Each posting links to its `applicationLink`, unchanged.
