# Adzuna

Adzuna's own job index in 19 countries. It shares the start of each posting; Dossier reads the rest from the posting's page.

- **Terms:** https://developer.adzuna.com/docs/terms_of_service
- **Countries:** AT, AU, BE, BR, CA, CH, DE, ES, FR, GB, IN, IT, MX, NL, NZ, PL, SG, US, ZA
- **Kinds of work:** any
- **Access:** Official API
- **Key:** A free application ID and key from [Adzuna's developer site](https://developer.adzuna.com/signup), with no card.
- **Credit:** "Jobs by Adzuna", linked to Adzuna's site for the posting's country.

Built into Dossier: each release bundles this config, and newer versions reach installs through the catalog between releases.
