# FreeHire

FreeHire's open catalogue: mostly tech postings read from companies' own career pages, in most countries, with their whole text. A self-hosted FreeHire can be used instead.

- **Terms:** https://freehire.me/terms
- **Countries:** Every country
- **Kinds of work:** tech
- **Access:** Official API
- **Key:** None. Free for your own job search; hosting Dossier for other people needs one of FreeHire's API plans.
- **Credit:** "Jobs by FreeHire".

Built into Dossier: each release bundles this config, and newer versions reach installs through the catalog between releases.
