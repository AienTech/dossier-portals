# Remote OK

Remote jobs, mostly in tech, from Remote OK's public feed. The feed has the newest postings and can't be searched, so Dossier reads it whole and matches it to your search on your server: every word in the title or company, Remote only, the country the job can be done from, and how recent.

- **Terms:** https://remoteok.com/api (the feed's first entry: link back to the posting on Remote OK and mention Remote OK as the source; don't use its logo)
- **Countries:** Every country
- **Kinds of work:** tech
- **Access:** Public feed
- **Key:** None
- **Credit:** "Jobs from Remote OK", linked to remoteok.com. Each posting links to its page on Remote OK.

Dossier downloads the feed at most once an hour, shared by every search.
